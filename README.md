# Missouri Reclaimed Cabinetry & Furniture

Static site for missourireclaimedfurniture.com, hosted on Cloudflare Pages.

- No build step. Cloudflare Pages: build command empty, output directory `/`.
- `_redirects` sends old WordPress URLs to the home page.
- `_headers` sets security headers.
- Gallery photos are listed in the script at the bottom of `index.html`.
